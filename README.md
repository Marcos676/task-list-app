# Task List App

Este proyecto es una aplicación de lista de tareas desarrollada en React. La aplicación se utiliza como práctica para demostrar conocimientos sobre el manejo de React.

## Características

- Añadir nuevas tareas
- Marcar tareas como completadas
- Eliminar tareas
- Filtrar tareas por estado (completadas, pendientes)

## Tecnologías Utilizadas

- React
- JavaScript (ES6+)
- HTML5
- CSS3

## Instalación

1. Clona el repositorio:
    ```bash
    git clone https://github.com/tu-usuario/task-list-app.git
    ```
2. Navega al directorio del proyecto:
    ```bash
    cd task-list-app
    ```
3. Instala las dependencias:
    ```bash
    npm install
    ```

## Uso

1. Inicia la aplicación:
    ```bash
    npm start
    ```
2. Abre tu navegador y visita `http://localhost:3000` para ver la aplicación en funcionamiento.
